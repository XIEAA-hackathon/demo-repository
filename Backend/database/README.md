# Database

PostgreSQL is required at runtime. SQLAlchemy is the ORM, and Alembic manages schema versions.

[../migrations/versions](../migrations/versions/) is the authoritative migration history. [schema.sql](schema.sql) is a complete, human-readable schema-only snapshot generated by applying that history to an empty PostgreSQL 16 database through revision `20260919_0006`.

The snapshot contains 21 application tables and the Alembic version table, including the migration-managed `event_activity_log` table that is not currently mapped in the ORM. It preserves database defaults, sequences, keys, checks and indexes; Python/ORM defaults are not automatically PostgreSQL server defaults. No application data, version-row data, credentials, ownership or grants are included.

Configure `Backend/.env` from [../.env.example](../.env.example) with a local PostgreSQL `DATABASE_URL`. Initialize or upgrade the schema from the repository root:

```bash
cd Backend
python -m alembic upgrade head
```

Inspect the database's current revision:

```bash
python -m alembic current
```

Inspect available migrations:

```bash
python -m alembic history
```

Production upgrades also use `python -m alembic upgrade head` under the operator's normal backup and change-control process. The SQL snapshot does not replace Alembic, record an applied revision or execute its data migrations. Application startup checks the schema; it does not migrate it.

For first-time environment setup, see the [root README](../../README.md#running-locally).
